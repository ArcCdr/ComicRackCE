# PagesView (ComicRack/Controls/PagesView.cs, .Designer.cs; inside it an ItemView)

Mac view: `Controls/CrPageList` (the list, a chrome control) over `Editor/PageListModel` (rows, columns, sorting, selection and the commands), the menu `Views/PagesContextMenu`, the pictures `Editor/PageRowThumbnails`. The Info dialog's Pages tab hosts it (`Views/InfoPagesPage`, `ComicBookDialog.md`); the pages view of the open book (P5.23b, `ComicPagesView`) uses the same three pieces on the open book. Ledger IN.06, PV.02 to PV.05 (done here for the dialog; PV.01 to PV.05 are finished by P5.23b for the main window); decision C-INFO-3.

## 2. Layout
- Detail view (the default): a 20 high column header (`HeaderControl`: sort arrow at the top centre, a click sorts, the separator at the right of a header resizes the column) over rows of the item font height plus 6 (12 to 48 with Cmd and the wheel). Columns in order, with the Designer's widths: Page 40 (right), Thumbnail 80, Type 80, Size 80 (right), Width 60 (right), Height 60 (right), Name 150, Bookmark 150, Rotation 60 (right), Position 60. The columns are wider than the view, so the list scrolls sideways. Every second row, starting with the first, has the `Cr.DetailRowHighlight` stripe. The thumbnail of a row is as wide as its cell less 2 with the page's aspect ratio, so a row cuts it off (the original draws it the same way); it has a black one unit frame, the bookmark flag, and the deleted picture at the bottom left for a deleted page.
- Thumbnail view: a cell is the picture's square (128, 96 to 512 with Cmd and the wheel) plus 4 around and the 4 unit shadow; the picture fits the square with its aspect ratio, a one unit frame, the page number badge at the top right, the bookmark flag, the deleted picture.
- Tile view: a cell of 192 x 96 (height 64 to 512, the width twice the height) plus 4 around; the picture at the left (half the width at most), the lines of text beside it (`ComicTextBuilder.GetTextBlocks(ComicPageInfo ...)`: "Page #N" bold, the type, a gap of 10, the size, the resolution, the rotation when it is not 0, a gap of 6, the bookmark), the font 0.8 to 1 times the list font by the cell height.
- Paper `Cr.ItemViewMainBack`; selection by `StyledSelection` (square corners, a one unit frame and a flat fill in the selection colour, the focused or unfocused colour by the view's focus); the scroll bars are the stock ones.

## 3. Menu (`contextPages`, in this order; texts from the `PagesView` section, the enum values from `ComicPageType` and `ImageRotation`)
Page Type (a check item for each browsable `ComicPageType`: Front Cover, Inner Cover, Roundup, Story, Advertisement, Editorial, Letters, Preview, Back Cover, Other, Deleted; Alt+Shift+A, B, C ...), Page Rotation (None, 90°, 180°, 270° with the pictures `Rotate0Permanent` ... `Rotate270Permanent`; Alt+Shift+6 to 9), Page Position (Default, a line, Near, Far), a line, Set Bookmark... (Cmd+Shift+B), Remove Bookmark (Cmd+Shift+D), a line, Move to Top (Option+Cmd+T), Move to Bottom (Option+Cmd+B), Reset original Order, a line, Copy Page (Cmd+C), Merge Pages, a line, Select All (Cmd+A), Invert Selection, Refresh (`RefreshThumbnail`), a line, Mark as Deleted (Delete, picture `EditDelete`). The Page Type, bookmark and move items show only when the pages can be edited; Merge Pages only for two selected pages; the checks show what all selected pages share. The shortcuts are also keys of the page that hosts the list (a native menu item takes its key only while the menu is open). Backspace is an alias of Delete.

## 4. Behaviour
- Rows: a row for each page of the book's copy in the order the book holds them (`FillList`: `max(page count of the file, page count of the book)` once the file's index is complete), filtered by `PageFilter` (the dialog shows every page, deleted ones too); the name of the image in the file is the Name column. The list is sorted by the Page column at the start. A header or Arrange by item sorts by the column (the same column flips the order) with the comparers of the original; a sort by a column that a command changes puts the edited row where it belongs.
- Selection (`UpdateSelectionFromMouse`, `OnKeyDown`): a click selects the page, Cmd toggles it, Shift selects from the anchor (the page of the last plain click) and with Cmd adds the range, an empty area clears; the arrow keys, Page Up, Page Down, Home, End move the focus and the selection (Shift extends, Cmd moves only the focus), Space toggles, Cmd+A selects all, Return and a double click activate. A context click on an unselected page selects it alone, on a selected one keeps the selection.
- Commands act on the selected pages: type, rotation, position; Mark as Deleted flips each page between Deleted and Story; the bookmark of one selected page (the name dialog proposes the bookmark or "Page N"); Move to Top and Bottom keep the pages selected (the bottom move of front cover pages makes them "Other" and the page after them the cover); Reset original Order keeps the selection; Refresh drops the pages' pictures from the Core's pool and the list; Merge Pages puts the two pictures side by side into the pool under the first page's key and marks the second page as deleted.
- Pictures: the thumbnail service's, at 256 high in the detail view and the size of the cell otherwise; a picture belongs to the page's image, rotation and size, so moving pages asks for nothing again. The Width, Height and Size columns fill in as the pictures and the file index teach the book its page sizes.
