Method:

- Errors in Common must not hide errors in Engine or Plugins, so the Engine and Plugins builds compile the upstream sources in directly (`CensusMerged=true`, no `ProjectReference`). The results of the three builds are merged and de-duplicated.
- **The tables below use the full Roslyn diagnostics (0 errors).** `dotnet build` (csc) stops before it binds method bodies when declaration-level errors exist (missing types in usings, signatures, base types), so it reports only **0** of them (declaration phase). The tool asks MSBuild for the exact compile inputs (`-getItem:Compile,ReferencePathWithRefAssemblies`) and asks Roslyn for every diagnostic, method bodies included.
- Errors that only appear once a type is fixed (for example a member lookup on a type that is currently unresolved) are still not counted, so the total remains a lower bound on the work, but much closer to it.
